# KOOORA LIVE — كورة لايف

تطبيق ويب عربي متجاوب لجدول ونتائج كرة القدم العالمية.

## التشغيل
افتح `index.html` عبر متصفح حديث أو انشر المستودع باستخدام GitHub Pages.

## البيانات
يجلب التطبيق جداول ونتائج المباريات من واجهة ESPN العامة. تغطية البطولات وتوفر البيانات يعتمدان على المزود، وقد لا تظهر كل مباريات العالم.

## البث
لا يستضيف التطبيق بثاً تلفزيونياً. زر «ابحث عن الناقل الرسمي» يساعد المستخدم في العثور على جهة البث المرخصة حسب المباراة والبلد. يلزم الحصول على حقوق البث وإضافة تكامل مرخص إذا أريد تشغيل الفيديو داخل التطبيق.

## التحديث
تحديث يدوي، وتحديث تلقائي كل دقيقة عند عرض تاريخ اليوم. تُعرض المواعيد حسب المنطقة الزمنية المحلية للجهاز.

## ملاحظة النشر
لتفعيل رابط عام من GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
