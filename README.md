# KOOORA LIVE — كورة لايف

تطبيق ويب عربي متجاوب لمتابعة جداول ونتائج كرة القدم.

## المزايا
- مباريات اليوم والأيام السابقة والقادمة عبر اختيار التاريخ.
- تصفية المباريات: الكل، مباشر الآن، قادمة، انتهت.
- البحث عن الفرق والبطولات.
- توقيت المباراة حسب المنطقة الزمنية المحلية للجهاز.
- تحديث تلقائي كل دقيقة عند عرض مباريات اليوم، مع زر تحديث يدوي.
- واجهة متجاوبة للهاتف والكمبيوتر، مع دعم التثبيت كتطبيق ويب (PWA) وإتاحة واجهة التطبيق دون اتصال بعد أول زيارة.

## مصدر البيانات وحدود التغطية
يجلب التطبيق النتائج من واجهة ESPN العامة لمجموعة من الدوريات والبطولات. التغطية ليست شاملة لكل مباريات العالم، وقد تختلف حسب توفر بيانات المزود؛ لذلك لا يصح اعتبار عدم ظهور مباراة دليلاً على عدم إقامتها.

## البث المباشر
التطبيق لا يستضيف بثاً تلفزيونياً ولا يتجاوز حقوق الناقلين. زر المشاهدة يوجّه إلى البحث عن الناقل الرسمي للمباراة. يلزم تكامل مع مزود بث مرخّص وحقوق مناسبة لعرض الفيديو داخل التطبيق.

## التشغيل والنشر
- افتح `index.html` في متصفح حديث، أو انشر المستودع عبر GitHub Pages.
- لتفعيل GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
- بعد النشر، افتح رابط GitHub Pages على الهاتف واختر «إضافة إلى الشاشة الرئيسية» لتثبيت نسخة الويب.

## الملفات
- `index.html`: واجهة التطبيق ومنطق جلب وعرض المباريات.
- `manifest.json`: بيانات تثبيت تطبيق الويب.
- `sw.js`: تخزين ملفات الواجهة الأساسية للاستخدام عند انقطاع الاتصال.
- `icon.svg`: شعار كورة لايف.
